IDE Core Engine

A modular, open-source IDE backend combining a piece table buffer, LSP client, autonomous ReAct agent, Monaco UI, xterm.js terminal, and Git integration.

GitHub Get Started

Features

Piece Table Buffer

Immutable original text and append-only add buffer for non-destructive editing.

LSP Client

Async JSON-RPC language server client with diagnostics, completion, and incremental sync.

Autonomous ReAct Agent

Iterative tool loop with file, search, shell, and diagnostic tools.

Monaco UI

Monaco Editor frontend connected over a single WebSocket.

xterm.js PTY

Persistent shell PTY streamed to the browser terminal.

Git Integration

Status, staging, commits, and per-file diffs powered by Git.

Architecture

Quick Start

pip install -r requirements.txt
pip install python-lsp-server
python -m ide_core.server

Open frontend/index.html in your browser to connect.
